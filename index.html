📚 MODUL MATERI HTML

Level 1: Sejarah HTML (Easy)

HTML (HyperText Markup Language) diciptakan oleh Tim Berners-Lee di CERN pada tahun 1991. Dikelola oleh konsorsium W3C & WHATWG hingga era HTML5 modern.

Level 2: Cara Kerja HTML (Medium)

Web Browser (Client) mengirim HTTP request ke Web Server. Server membalas dengan dokumen HTML yang kemudian di-parse oleh browser menjadi hirarki DOM (Document Object Model) untuk dirender visual.

Level 3: Atribut HTML (Hard)

Atribut memberikan instruksi tambahan pada tag. Contoh: href untuk tautan ``, src & alt untuk gambar ``, target="_blank" untuk tab baru, serta atribut global seperti class, id, dan style.

Level 4: Tag & Struktur HTML (Expert)

Struktur utama: <!DOCTYPE html>, <html>, <head>, dan <body>. Tag Semantik modern meliputi <header>, <nav>, <main>, <article>, serta <ol> (ordered list) dan <ul> (unordered list).
